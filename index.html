Cómo funciona una conexión

Cada titular de cuenta debe autorizar el acceso a los servicios correspondientes mediante los mecanismos de autorización de cada plataforma.

01 / VINCULACIÓN

El cliente inicia la conexión

Desde el sistema de gestión, el usuario selecciona el servicio que desea vincular.

02 / AUTORIZACIÓN

Autoriza los permisos

La plataforma externa presenta su propio proceso de inicio de sesión y autorización.

03 / INTEGRACIÓN

Se habilitan las funciones

El sistema utiliza los accesos concedidos para las operaciones incluidas en la integración.

Información importante

Este es un sitio informativo de servicios de desarrollo e integración de software. No procesa pagos ni solicita contraseñas, datos bancarios o credenciales de los visitantes. Las integraciones son independientes y no implican afiliación, representación ni respaldo por parte de Mercado Libre, Mercado Pago u otras plataformas mencionadas.
